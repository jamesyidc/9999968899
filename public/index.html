① 系统概述

本系统是一套原油进口到岸价格（CIF）追踪平台，同时收录两类口径的数据：

🏛️ 官方周度综合到岸价
由海关总署 + 上海石油天然气交易中心联合发布，覆盖全国所有进口原油的加权平均 CIF，每周三约 09:29 更新上一整周数据，是行业公认最权威的基准。
⚡ 实时测算单日到岸成本
基于外盘布伦特报价 + VLCC运费 + 迪拜升贴水 + 汇率实时推演的每日理论到岸成本，每个交易日 16:30 自动采集，适合当日行情判断。
② 数据来源与发布规律
数据类型发布机构发布时间覆盖周期滞后说明
官方周度指数 上海石油天然气交易中心

📅 为什么本周（7/11-7/15）官方数据为空？
官方指数每周三发布"上一周"的加权均值。今天（7/15，周二）尚未到发布日，7/7-7/13 这一周的数据将在明天（7/16，周三）09:29 左右由上海油气中心公布，届时系统将在 10:30 自动采集写入。这是正常的业务节奏，不是系统故障。
③ 核心业务公式
官方周度换算
吨价（元/吨） = 指数 × 31.14
基期：2018年第1周 = 3114元/吨 = 100点，31.14为基期吨价÷100
实时到岸测算（中东阿曼/迪拜）
CIF(USD/桶) = 布伦特 − 贴水 + OSP溢价 + 运费保险
CIF(元/桶) = CIF(USD) × 汇率
CIF(元/吨) = CIF(元/桶) × 7.33
典型参数：贴水3美元、OSP溢价1.5美元、运费+保险约11-13美元/桶
单位换算
1吨原油 ≈ 7.33 桶
含税到岸价 = CIF × 1.13（含13%增值税）
CIF = Cost + Insurance + Freight（到岸价，不含关税增值税）
价差含义
差价 = 实时测算 − 官方周度
正值：当前新到港成本高于上周历史均价（近期油价上涨）
负值：当前成本低于历史均价（近期油价下跌）
④ 自动采集系统运行逻辑
每周三 09:29
→
上海油气中心发布官方周度指数（HTML文章页面）
每周三 10:30
→
node-cron 定时触发 → 爬取 shpgx.com/html/xyzx/ 列表页 → 正则匹配 title 属性含"原油综合进口到岸价格指数"的文章链接 → 抓取文章页解析：指数值、周期、环比、同比、发布时间戳 → 自动换算：指数×31.14=元/吨 → ÷7.33=元/桶 → ÷汇率=美元/桶 → 写入 data/official_weekly.jsonl（去重，已存在则跳过）
每交易日 15:00
→
上海国际能源交易中心 SC原油期货日盘收盘
每交易日 16:30
→
node-cron 定时触发 → 多源采集（三级回退机制）：
· 布伦特：investing.com → 财联社CLS → FRED(EIA)
· WTI：财联社CLS → 布伦特估算（−4.5 USD）
· SC期货：chemall.com.cn
· 汇率：东方财富API → 腾讯股票接口 → 6.92固定值
→ 代入公式计算 CIF → 写入 data/realtime_daily.jsonl

→
错误写入 collector.log，更新 collector_state.json 错误字段，前端「自动采集」Tab 红色显示，支持手动重新触发

⑧ 常见问题 FAQ
Q：为什么官方数据本周（如7/11-7/15）是空白的？
A：正常。官方指数每周三发布"上一整周"数据，存在7-10天的结构性滞后。本周数据将在下周三09:29发布，系统10:30自动采集。空白不代表数据缺失，代表尚未到发布节点。
Q：实时测算与官方数据有差距，哪个更准？
A：两者口径不同。官方数据是全品类（中东、俄油、西非等）真实海关成交的加权均值，准确度最高；实时测算仅代表"新到港中东阿曼/迪拜油"的理论成本，两者差价在±200元/吨属正常范围。
Q：曲线图中两条线为什么有时不重叠？
A：官方线（蓝）每周只有一个数据点（周三），其余日期为空（spanGaps:true跳过断点不连线）；实时线（紫）每交易日均有数据。X轴采用统一时间轴对齐，两者在同一天的位置是对齐的。
Q：自动采集失败怎么办？
A：进入「🤖 自动采集」Tab 查看日志定位错误，点击"手动触发"按钮重新采集；或在「➕ 录入数据」Tab 手动填入数据。采集器内置三级数据源回退，单一来源异常一般不影响整体。
Q：SC期货与到岸价的关系？
A：SC低于理论到岸价时，进口套利窗口关闭（进口亏损）；SC高于理论到岸价时，进口有利润空间。两者价差反映市场对未来供需的预期。
Q：数据如何持久化保存？
A：所有数据以 JSONL 格式存储于磁盘文件，每行一条记录，追加写入、从不覆盖历史。重启服务器不丢失数据。可通过「导出CSV」备份全量数据。

📖 系统说明

🏛️ 官方权威周度原油综合到岸价

  • 来源：上海石油天然气交易中心（SHPGX）+ 海关数据，每周三更新
  • 口径：全国所有进口原油加权平均 CIF，滞后约一周
  • 换算：实际到岸吨价 = 指数 × 31.14（元/吨）
  • 含税价：CIF × 1.13（含 13% 增值税）
  • 用途：复盘石油企业季度成本、长线基本面分析
  • 官网：www.shpgx.com → 资讯/指数专区 → 中国原油综合进口到岸价格指数

⚡ 实时单日理论到岸成本（中东阿曼/迪拜口径）

  • 数据来源：布伦特/WTI + VLCC运费 + 升贴水 + 汇率，动态测算
  • 计算公式： CIF(USD) = 布伦特 − 贴水 + OSP溢价 + 运费保险
    CIF(元/桶) = CIF(USD) × 汇率
    CIF(元/吨) = CIF(元/桶) × 7.33
  • 参考运费：中东→中国 VLCC 运费+保险约 11~13 USD/桶
  • 用途：短线预判原油板块、油气股竞价波动
